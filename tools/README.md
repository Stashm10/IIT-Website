# Rebuilding the site

The site is plain static HTML (GitHub Pages). Everything under `data/`, `band/` and
`index.html` is generated by the two scripts here.

## Setup (once)

```bash
python3 -m venv venv
venv/bin/pip install -r tools/requirements.txt
```

## 1. Build the data (`data/`)

Reads the 2018 `.h5` files **read-only** from
`IIt_Project_V2/2018 IITSO Wideband Data` and the band plan from `IIt_Project_V2/bands.json`
(override the folders with the `IIT_V2_DIR` / `IIT_DATA_DIR` environment variables).

```bash
venv/bin/python tools/build_data.py --workers 6
```

- Each day is cached in `tools/cache/<date>.json`; re-running only processes missing days.
- Files on the same date are pooled into one day.
- Files that cannot be opened are skipped and listed on the overview page.
- If `bands.json` changes, delete `tools/cache/` and run again.

## 2. Build the pages

```bash
python3 tools/build_site.py
```

Edit `tools/templates/*.html` and `assets/*` for layout changes, then re-run this step.

## Tests

```bash
cd tools && ../venv/bin/pytest -q
```

`test_reference.py` checks Jan 1 2018 against `reference_2018-01-01.json` for all 91 bands.

## How months are combined

Every day stores a histogram on fixed 0.5 dB bins (-150 to +20 dBm). A month (or the whole
year) is the exact sum of its days' histograms, so every reading counts equally. The pooled
mean, min and max are exact; the pooled median and percentiles are read off the summed
histogram (within the 0.5 dB bin width).
